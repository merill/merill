### 🛡️ Maester

[**Maester**](https://maester.dev) is the open-source test automation framework and security analyzer for Microsoft 365, built with a great community of contributors. It turns security best practices into tests you can run against your tenant every day.

[![Installs](https://img.shields.io/powershellgallery/dt/Maester?label=installs&color=2563eb)](https://www.powershellgallery.com/packages/Maester)
[![Stars](https://img.shields.io/github/stars/maester365/maester?color=2563eb)](https://github.com/maester365/maester)

[**Maester Cloud**](https://maester.cloud) is the evidence layer on top of it: drift detection, multi-tenant visibility and years of searchable tenant history, self-hosted or fully managed.
